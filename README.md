# Latihan Mandiri SAS 1 · Informatika Kelas VIII

Latihan mandiri di rumah untuk persiapan SAS 1 Informatika kelas VIII SMP Labschool Jakarta (Himpunan Data Terstruktur).

- 50 soal: 35 pilihan ganda, 7 pilihan ganda kompleks, 8 benar–salah, waktu 90 menit.
- Masuk dengan kelas, kode kelas dari guru, dan nama.
- Setelah mengirim jawaban, nilai, umpan balik per materi, kunci, dan pembahasan langsung tampil.

Kunci jawaban tidak disimpan di halaman ini; penilaian dilakukan di server sekolah.
